# DP-FedVAE: Differentially Private Federated Variational Autoencoder for IoT Zero-Day Threat Detection

## Overview

DP-FedVAE is a privacy-preserving federated learning framework for IoT zero-day threat detection.

The framework combines a Variational Autoencoder (VAE), Federated Learning (FL), and Differential Privacy (DP) to detect anomalous IoT network traffic while preserving client privacy.

The experiments are conducted using the N-BaIoT dataset under both benign and adversarial federated-learning scenarios.

---

## Key Contributions

The main contributions of this work include:

- A federated Variational Autoencoder framework for IoT anomaly and zero-day threat detection.
- Integration of Differential Privacy into federated model aggregation.
- Gradient clipping and Gaussian noise mechanisms for privacy protection.
- Evaluation under a model-cancelling malicious-client attack.
- Evaluation using device-wise non-IID IoT data.
- Comparison of clean, adversarial, and differentially private federated-learning scenarios.

## Dataset

The experiments use the **N-BaIoT** dataset.

The dataset contains network traffic generated by nine IoT devices, including benign traffic and traffic associated with the Mirai and BASHLITE/Gafgyt botnets.

The dataset itself is not included in this repository.
